# 🏨 Hotel Management System

A **Java-based Hotel Management System** designed to simplify basic hotel operations through a console-based application. The project demonstrates Object-Oriented Programming (OOP) concepts in Java and provides functionality for managing hotel rooms and related operations.

## 🚀 Project Overview

The Hotel Management System is developed using Java to handle basic hotel management activities. It includes different room categories, room availability handling, and food-related functionality.

The project focuses on applying Java fundamentals and OOP concepts to solve real-world hotel management problems.

## ✨ Key Components

- **Room Management:** Supports single and double room categories.
- **Room Availability:** Handles room availability and unavailable-room scenarios.
- **Food Management:** Includes food-related functionality.
- **Hotel Operations:** Organizes hotel-related operations through Java classes.
- **Object-Oriented Design:** Uses separate classes to structure the application.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Classes and Objects
- Exception Handling (where implemented)

## ⚙️ Installation and Execution

### Prerequisites
- Java Development Kit (JDK 8 or above)
- Any Java IDE (VS Code, IntelliJ IDEA, or Eclipse)

### Steps to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Mansoorsk12/HotelManagement.git
   ```

2. Navigate to the project directory:

   ```bash
   cd HotelManagement
   ```

3. Compile the Java source file:

   ```bash
   javac Main.java
   ```

4. Run the application:

   ```bash
   java Main
   ```
